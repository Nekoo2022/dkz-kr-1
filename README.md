# Каталог книг — дополнительное контрольное задание №1

Клиент-серверное приложение на React и Express. Вместо сущности User реализован каталог книг.

Сущность **Book**:

| Поле | Смысл |
| --- | --- |
| `id` | идентификатор |
| `title` | название |
| `author` | автор |
| `genre` | жанр |
| `publishedYear` | год издания |
| `pages` | число страниц |

Данные хранятся в памяти сервера. После перезапуска каталог возвращается к трём стартовым книгам.

## Запуск

Нужны Node.js и npm. Сервер и клиент запускаются в двух терминалах.

### Сервер

```bash
cd backend
npm i
npm run dev
```

- API: http://localhost:3000/api/books
- Swagger UI: http://localhost:3000/api-docs

### Клиент

```bash
cd frontend
npm i
npm run dev
```

Интерфейс: http://localhost:3001

Сначала запускайте сервер, затем клиент. Иначе страница не сможет загрузить список.

## REST API

| Метод | Путь | Действие |
| --- | --- | --- |
| GET | `/api/books` | список книг |
| GET | `/api/books/:id` | книга по идентификатору |
| POST | `/api/books` | добавить книгу |
| PATCH | `/api/books/:id` | изменить книгу |
| DELETE | `/api/books/:id` | удалить книгу |

Пример тела для добавления:

```json
{
  "title": "1984",
  "author": "Джордж Оруэлл",
  "genre": "Антиутопия",
  "publishedYear": 1949,
  "pages": 328
}
```

Те же запросы есть в `backend/api.http` и в Swagger UI (кнопка Try it out).

## Что показать

1. Сервер на порту 3000 и клиент на порту 3001.
2. Список книг, который React получает с API.
3. Добавление, изменение и удаление книги в интерфейсе.
4. Swagger UI по адресу http://localhost:3000/api-docs: схема Book и все CRUD-операции.
